# Real / Sim — interactive physical assets

Published frontend: https://jiabins0303.github.io/genesis-demo/

This repository contains the compiled website and public recorded demonstration
media only. GPU simulation, model checkpoints and application source remain
outside this publishing repository. Live interaction connects to RunPod when
the GPU service is available; recorded calibration can be explored while offline.

Research assets and methods: [PhysTwin](https://github.com/Jianghanxiao/PhysTwin)
and [Real2Sim-Eval](https://real2sim-eval.github.io/).
